# Contributions / Участие в разработке

MultiParser is a community-friendly unfinished Windows parsing toolkit. We welcome bug reports, documentation, tests and pull requests.

## Before opening a PR

1. Open an issue describing what is broken or what you want to add, if the change is substantial.
2. Fork the repository and create a descriptive feature/fix branch.
3. Keep existing WB and Ozon entry points working, or explain a deliberate breaking change.
4. Include a reproduction, tests where practical, and Windows run instructions.
5. Explain whether your change was actually verified or only reviewed statically.
6. Open a PR with the summary and the affected module(s).

**Never** attach filled JSON configs, `.env`, keys, Telegram tokens, authenticated cookies, proxy credentials or private scraped data. Redact logs and screenshots.

Potential help: compatibility and install tests, GUI polish, reusable parser interfaces, browser/selector updates, captcha integrations, automated testing and verified Windows packaging.
